#  Sistema Inteligente de Monitoramento Energético Espacial

Projeto desenvolvido para a Global Solution 2026 da disciplina de Ciência da Computação da FIAP.

##  Descrição

O Sistema Inteligente de Monitoramento Energético Espacial foi criado para monitorar sistemas energéticos de uma missão espacial experimental em tempo real.

A solução recebe dados simulados dos módulos da missão, realiza análises automáticas, gera alertas para situações críticas e auxilia na tomada de decisões operacionais.

---

##  Objetivo

Desenvolver uma plataforma inteligente capaz de:

- Monitorar condições operacionais da missão espacial;
- Analisar consumo energético e potência dos módulos;
- Detectar situações críticas automaticamente;
- Gerar alertas em tempo real;
- Executar respostas automatizadas para emergências simuladas;
- Apresentar informações de forma clara e organizada.

---

##  Funcionalidades

###  Monitoramento de Dados

O sistema acompanha continuamente:

- Temperatura dos módulos
- Nível de energia
- Comunicação
- Status operacional

###  Geração Automática de Alertas

Sempre que valores críticos são identificados, o sistema emite alertas para auxiliar a operação da missão.

Exemplos:

- Temperatura acima do limite seguro
- Nível de energia crítico
- Falha de comunicação
- Módulo inoperante

###  Tomada de Decisão Automatizada

O sistema utiliza regras lógicas para responder automaticamente a situações críticas, incluindo:

- Ativação de modo de emergência
- Redirecionamento de energia
- Priorização de módulos essenciais

###  Dashboard Operacional

Exibição organizada dos dados monitorados em tempo real para facilitar a análise da missão.
