## 🚀 Como subir no GitHub

1. Extraia o ZIP
2. Abra a pasta no terminal e rode:

```bash
git init
git add .
git commit -m "feat: sistema de monitoramento energético espacial - GS2026 FIAP"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/gs2026-espacial.git
git push -u origin main
```

3. **Antes de fazer push**, edite o `README.md` e preencha:
   - Tabela de integrantes (nomes e RMs)
   - Links do GitHub e YouTube

O sistema já foi testado e roda corretamente — mostra dashboard colorido com alertas, barras de progresso e tomada de decisão automática. Python 3.10+ sem nenhuma dependência externa.
